• # CLI Task Manager

  This is my first C project. It is a simple command-line task manager that allows users to create tasks with a name, description, and priority.

  ## Requirements

  - A C compiler such as GCC
  - A `task.txt` file in the project directory

  Create the required file before running the program:

  ```bash
  touch task.txt

  ## Compile

  gcc main.c -o taskmanager

  ## Run

  ./taskmanager

  The tasks you create will be saved in task.txt.

  ## About

  This is a small learning project created to practice the basics of C, including:

  - Structures
  - User input
  - File handling
  - Loops and conditions
